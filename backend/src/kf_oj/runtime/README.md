# 学习 Agent Runtime

`kf_oj.contracts.agent_runtime` 定义会话、运行和步骤记录。会话所有者由服务端认证后写入，运行引用会话与固定技能版本，通过摘要关联输入、配置及步骤结果。不要把源码、题包内容或凭据写入这些摘要字段。

运行从 `queued` 开始，领取后进入 `running`。可重试错误进入 `retry_wait`，到期后回到队列。未领取或等待重试的任务可以直接取消，运行中的任务先进入 `cancel_requested`。一旦取消获准，后续成功写入必须被拒绝。终态不再接受状态变更。

`AgentStorage` 由学习模块通过已认证的账号绑定。学习模块负责 PostgreSQL 记录的读写，它通过会话归属核对运行和步骤的访问权限。会话内的同一请求标识只能绑定一组输入和技能版本，重复请求返回已保存的运行。

运行状态变更和步骤写入先锁定本人运行并核对版本号。状态每变更一次都会增加版本号，旧写入因此不能在重试后覆盖当前运行。取消请求生效后，只能把正在进行的步骤记为已取消。这个版本号为运行记录提供条件写入，Worker 使用独立租约，租约过期或收回时版本检查拒绝旧实例写入。

工具注册表固定工具名、版本、输入输出模型、权限、只读属性、超时和重试策略。模型输入只有已登记工具名及参数，不决定以哪个账号或运行上下文调用。学习模块提供本人提交记录和训练候选工具，声明的授权范围仍需与当前账号、运行及已存储版本对应的技能授权匹配。

每次工具调用在 PostgreSQL 事务里检查登录状态、运行版本和当前技能工具授权，登记消耗的调用次数及在途槽位。额度按运行、账号和服务共享。失败也计一次，结束或到期归还在途槽位。返回前再次核对账号、运行和技能授权。只读工具超时可按任务租约的尝试上限延期重试。

四个固定学习流程读取运行所固定的技能参数，并通过权限门控获取有界的本人提交及可训练题目。提交复盘对照同一题目版本的连续有效判定。渐进式答疑当前可给有事实依据的概念提示，明确缺少代码定位时的降级。专项训练和阶段复习返回可核实的题目版本、顺序及候选缺口。

学习应用先存入请求及输入，领取后记录实际工具步骤，在同一事务内复核当前授权、保存结果并更新运行状态。独立 Worker 通过 PostgreSQL 领取，仅使用学习数据库权限。续接时复用已完成的工具检查点并复核原会话和技能授权。

可选模型提示使用 Responses 接口，由学习 Worker 在规则结果生成后按本次授权调用。每次运行最多发出一次模型请求，并计入账号和服务额度。提交复盘只发送评测统计及另行授权的代码变化计数和诊断类型。专项训练和阶段复习只发送已选题目的难度计数、时间设置及适用的目标覆盖数量。模型说明随运行记录显示，计划确认使用规则给出的题目与依据。模型失败或额度用完时保留规则结果。

提交复盘可另外授权发送修改区段的分支、循环和返回关键字计数。词法分析使用两份本人的同题同语言源码，跳过注释和字符串，最多处理各 512 行和 32 KiB。保存的结构证据和模型输入只有计数。词法计数的口径用于描述改动，不推断实际控制流、复杂度或改动正确性。无法读取区段时继续使用已授权的基础证据。

渐进式答疑的模型概念提示默认只发送选定的公开主题。用户可逐次授权引用一条本人评测。运行通过历史工具按标识和归属读取该记录，模型输入增加一项已完成的普通判定类别。页面保留原规则提示和本人证据链接，等待评测或缺少可用类别时只显示规则提示。

本人提交复盘的本地代码证据可显示单行条件的比较边界变化。只识别同类条件、相同两个简单操作数间的尖括号比较增减等号，记录行号及两个运算符，提示用公开样例核对相等时的行为。复盘的模型投影不含这项本地依据。

提交复盘另有逐次授权的线索选择。模型可从此次本人记录对应的类别中选择一类，执行流程以预先解析的本人提交标识调用一次既有历史工具。原记录能再次读回时展示该项依据。运行恢复重用模型及已完成工具的检查点。

用户确认训练草案时，学习模块重新核对技能授权、题目版本和候选条件。计划在同一事务绑定来源运行，并保存训练目标、节奏及草案提供的题目用时估计。多次确认返回同一份已保存计划。

用户可从本人计划生成下一轮。选题使用该计划保存的筛选条件和最新本人记录，保留原目标。用户可在生成前调整时间和频率，新计划重新分配题量及适用用时，原计划保留原节奏、选题和依据。新计划记录直接来源。

训练可选常规排序、难度自评优先或待巩固知识点优先。v6 分别以 `2/5/1` 和 `2/1/5` 给时间、难度自评、近期未解决评测加权，使用常规排序打破平局。计划保存策略和规则版本，题目现行版本、难度、可见性和先修条件仍由既有筛选执行。

运行详情按需读取最近十二步、领取次数和持久化的首次领取与终态耗时。工具总耗时只累计已结束的调用。旧运行缺少的时间保留为空。对外显示工具版本、状态与固定错误码，参数和输出正文只留在已有边界内。

已结束的模型步骤显示从数据库保留一次模型调用到步骤落库的耗时。账号、预算明细和未确认结果留在各自的存储边界。

模型未返回可用内容时，步骤摘要区分超时、提供商限流或拒绝、内容无效与一般不可用。结果仍保留规则提示，步骤中只记录固定原因码。

已完成的复盘和答疑允许本人保存、修改和撤回一份帮助程度反馈。反馈独立于原运行结果，学习 Worker 和模型不读取此表。
