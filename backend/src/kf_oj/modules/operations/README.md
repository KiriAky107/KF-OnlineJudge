# operations

维护审计通过 `public.py` 的追加端口写入调用方事务；本模块不成为评测状态的写入入口。
上传、解析完成/失败、丢弃、发布、下架与恢复记录真实账号、授权版本、操作 UUID、对象与
数据库时间。发布回执和审计同时提交；审计失败使整个业务事务回滚，不确认半发布。

本机受控身份 CLI 使用已核验的窄权限数据库函数。授权变化由固定包装函数在同一事务
追加审计，主体类型为 operator，操作者为数据库 `session_user`，对象为实际变更账号；
不把授予/撤销冒充成该账号自己的操作。旧账号事件保留 account 主体类型。

管理员 `/api/v1/admin/maintenance-audit` 按时间和 UUID 的复合游标递减读取，每页至多
100项，可选择有限动作类型；只展示已提交事件。导入失败动作仍是失败，committed 表示
审计事务提交。响应不含口令、会话令牌、工件引用、内部路径或任意诊断正文。

应用数据库角色无审计 UPDATE/DELETE 权限，数据库触发器还阻止历史改写。
导入 Worker 只有追加权限，不能读取整个维护审计；Coordinator 无审计写入权限。
节点管理、部署控制及跨账号业务管理仍未开放。
