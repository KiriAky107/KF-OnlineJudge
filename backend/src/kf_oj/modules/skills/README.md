# skills

负责声明式技能、不可变版本、个人绑定和后续分享。当前 `builtin/` 包含提交复盘、渐进式答疑、专项训练和阶段复习。每份 JSON 描述固定 Runtime 格式、方法、参数默认值和所请求的工具版本，以解析后的 JSON 内容计算 SHA-256，再由技能标识、发布号和摘要定位版本。修改已发布内容时新增版本文件，使已有版本仍可读取。

注册表提供按用途查找和按版本查找。参数按所选版本校验，默认值来自该版本。声明的工具不授予权限。每次 Runtime 调用仍需和服务端工具、账号及实时技能授权匹配。

个人绑定只向所属账号开放。启用时明确授予工具，并按选定版本校验参数。运行保存所属账号的不可变配置和工具范围。升级或修改偏好只影响以后发起的运行，停用或撤销工具授权会使旧运行的权限失效。再次启用时创建新的授权配置。

技能草稿仅作者可见。编辑使用修订号并保留最初复制的官方版本标识。Web 支持导入和导出受类型与体积限制的 JSON 声明。可复制官方或目录中已批准的版本。复制取其声明和默认参数，保留原许可、署名和直接来源；个人绑定与训练数据独立。

声明可内嵌最多四份 `references/` 下的单层 `.md` 或 `.txt` 资料。每份有唯一相对路径、最多 3,000 字符的正文和正文 UTF-8 字节的 SHA-256。草稿保存时生成摘要，导入已带摘要的包时校验与正文一致。声明整体仍受 16 KiB 限制。资料随修订送审并固定在已发布版本，由审核页与技能目录以纯文本展示。

作者可以固定已保存的私有修订，在学习助手选择工具权限并试用同一套固定流程。每份修订有独立版本与绑定，后续编辑不改动已发起的运行。私有版本不进入公开目录。Worker 只能通过当前有效领取的运行读取对应作者和修订的执行参数，教学方法等文字不会加入执行声明。

作者确认分享后，送审会保存该修订的独立声明、出处和摘要。作者可以撤回待审版本。管理员通过实时登录权限审核，批准后已登录用户可按名称和用途发现该版本，内容不随草稿编辑改变。审核说明只供作者和管理员查看。

作者可归档已发布版本。归档使目录、公开版本详情、新绑定和复制入口停止提供该版本。已绑定的账号可以沿用原版本和授权，管理员仍可对归档版本执行停用。归档记录和停用记录分别保存。

平台公开版本可针对具体版本进行个人绑定和授权，升版只影响之后发起的运行。独立 Worker 通过受限数据库函数读取已发布版本的执行参数与工具范围；教学方法与署名供用户查看。固定流程使用该版本的用途、参数及本人实际批准的工具。

社区评分随公开版本独立统计。每位登录用户可保存、更新或撤回本人的 1–5 分评价。目录显示该版的平均分和样本量，个人评分只对本人返回。

举报和处理说明只有举报人和管理员可以查询。对确认有问题的版本，管理员可以另行停用，保留原来审核通过的版本内容。目录与执行工作进程会停止提供停用版本。修订内容可以发布到新的版本，已有绑定需要用户主动选用。
