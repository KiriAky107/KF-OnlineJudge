# learning

M5-A 提供本人真实学习统计、确定性规则推荐、持久化个人训练计划与备注。
通过 problems/submissions 的 `public.py` 投影读取其他域，不读取其 ORM。

- 概况为最近 90 天最多 500 次提交；一次 submission 是一次学生尝试，基础设施 attempt 不增加计数。返回实际范围、截断、普通样本、元数据修订和来源引用；AC 按版本记录，逻辑题汇总只表示范围内任一版本通过。
- pending、取消、基础设施失败不计入普通错误判定。普通判定只描述结果，不推断知识点掌握。
- 普通推荐和学习助手按真实当前版本、用户标签及难度筛选。本人最近 7 天提交过的版本和安排过的题目靠后。同一版本距离最近一次通过满 14 天且近期未重复时优先复习。提交日期独立查询本人全历史，难度自评、相关未解决普通判定和稳定 ID 用于进一步排序。推荐与计划保留本次判断所用日期。业务数据缺失时仍列出符合筛选条件的题目并说明数量缺口。
- 管理员可按题目版本填写先修知识点。普通推荐和学习助手只选择本人已取得这些知识点通过记录的候选题。依据取自目前可见的已发布版本，链接到本人提交。缺少依据的候选说明需要先练习的知识点。保存计划时复核当前条件与记录，并保留使用的证据快照。
- 用户可选择将多个知识点分配到一组题。该选项在现有难度、先修和候选数量限制内选择覆盖最多目标的一组题；同等覆盖时优先较小的组合并沿用现有排序补足题量。推荐和保存的计划显示覆盖情况与缺口。默认要求单题匹配全部标签。
- 候选先在数据库匹配全部目标标签/难度，再限定稳定 ID 排序的前 500 题；接口显式报告截断。计划列表展示本人最近 50 个及截断标识，历史计划详情保留固定链接。
- 创建时重新检查候选并保存元数据/理由/证据快照，同账号请求幂等键防双击重复。后续改标签不修改历史快照。
- 计划进度独立查询本人、固定版本及计划创建时间下界；任一AC完成且不因后续WA回退。备注需计划和条目同时属于本人，不修改判题结果。
- 旧发布版本与禁用不同：旧版可用时显示旧版提示，不悄悄换成新版本。

迁移由唯一 Alembic 入口处理；新表仅授予平台需要的读写权限，不授予 Coordinator。旧已发布题目版本不可变性保持不变。API 使用现有认证、CSRF 与 no-store。

Agent 会话和运行使用独立的表。Runtime 的只读工具由学习模块绑定到已认证账号和最新的技能授权。运行使用技能模块保存的本人版本与配置快照，每次调用复核该绑定的实时授权。模型分析、代码差异诊断和推荐效果实验仍待接入。测试中的构造评测记录只能验证业务投影，不能声称真实沙箱提交已验收。

学习任务与运行同事务入队。使用具备 `kf_oj_learning_worker` 角色的独立数据库登录设置 `KF_OJ_LEARNING_DATABASE_URL`，
运行 `kf-learning-worker --check` 核对权限，运行 `kf-learning-worker` 消费队列。Worker 锁定任务并续租，
从私有检查点恢复成功的只读步骤。取消使执行版本失效，重新登录不能恢复旧会话已撤销的作业授权。

Web 入口是训练页中的学习助手。它通过 `/api/v1/learning/agent/` 下的接口读取本人的技能配置和最近 30 次运行。配置、运行、取消和计划确认复用平台 Cookie 会话及 CSRF。启动请求在同一会话内去重，队列最多容纳每账号 4 个、全服务 200 个活跃任务。训练草案经确认后才成为个人训练计划。

提交复盘与渐进式答疑 v2 允许在用户授权且本次选择使用时生成代码证据。API 按本人范围读原始工件，只向 Worker 保存提交、评测和题目版本的引用、差异行号和诊断位置。比较仅限同一题目版本和语言，最多比较前 512 行并返回 16 段。编译位置仅保留可映射到本人源码的行号。已有 v1 配置和历史运行仍可查看。

请求局部修改时，渐进式答疑可针对已确认的编译诊断提供行号和修改动作，支持 C/C++ 与 Java 缺少分号，以及 Python 缺少冒号、括号或语句体缩进。仅保存诊断类别及源码位置。启用示例时显示对应的通用语法。缺少可归类诊断时继续提供位置或概念线索。

训练条目支持本人难度自评。后续推荐查看最近 90 天最多 50 条本人自评，并在同知识点可用题目中调整优先难度。显式选择的知识点及难度依旧限制候选。计划固定生成时的自评来源，修改或清空自评只影响后续选择。完成状态仍从本人真实评测计算。

学习 Worker 可选接入 OpenAI Responses 格式的模型服务。由服务环境设置
`KF_OJ_LEARNING_MODEL_BASE_URL`、`KF_OJ_LEARNING_MODEL_NAME` 和远端需要的
`KF_OJ_LEARNING_MODEL_API_KEY`。支持 HTTPS 服务或显式指定的本地 HTTP 服务。
对于支持关闭思考的模型，可设置 `KF_OJ_LEARNING_MODEL_REASONING_EFFORT=none`。
自由答疑可用 `KF_OJ_LEARNING_CHAT_REASONING_EFFORT` 独立设为 `none`、`low` 或 `high`。
未显式设置自由答疑的思考档位时，由模型服务采用自身默认值。直接连接 DeepSeek 时，短提示默认关闭思考。

渐进式答疑可选择概念主题，只有所选公共主题进入模型请求，每次运行至多请求一次。
服务失败或接续时缺少响应会显示规则提示。运行记录保留
模型版本、实际返回的 token 和延迟。有需要时可在设置模型服务的学习 Worker 上开启，
未配置时规则提示照常提供。

Responses 调用在数据库持久化保留记录。学习 Worker 使用滚动一小时的账号和服务共享请求额度，默认分别为 12 和 120，可用 `KF_OJ_LEARNING_MODEL_ACCOUNT_CALLS_PER_HOUR` 和 `KF_OJ_LEARNING_MODEL_SERVICE_CALLS_PER_HOUR` 调整。单账号同一时间最多 1 个请求，服务同一时间最多 4 个请求。预设技能的每次请求最多输出 128 token。自由答疑沿用模型服务的输出设置，调用最多等待 120 秒。响应无法确认时，该次请求仍计入额度。

提交复盘可单独选用模型建议。基础请求包含该次复盘的本人评测计数、同题版本变更计数及范围截断标志。
同时选用本人代码证据时，用户可以另外同意将改动数量和已识别的编译问题类别纳入本次建议。
改动计数只取本次复盘范围内的同版本、同语言、已完成评测，无源码、诊断原文或提交标识外发。
页面分别显示评测依据和模型待核对建议；缺少有效评测记录时直接返回已有证据状态。


自由答疑接受用户自拟问题。同一题目版本或通用会话可接续最近三轮普通对话。模型收到的做题概览最多包含近 30 天内最近尝试过的八道公开题，字段为题名、难度标签、难度分和同版本是否通过。提交判定、语言、资源指标和测试点计数仅在用户授权该轮读取对应提交后提供。经用户确认的源码片段仅发送到本机模型。含提交详情或源码的轮次仍可由本人看历史，但不会被自动添入后续的模型请求。
模型返回的可见思考文本单独显示，只能由本人读取，不进入后续模型请求。聊天保留完整正文，后续请求只带每轮历史答复的前 6000 字符。运行中的思考与正文预览随任务终止清理。

题目答疑按 L0 到 L3 逐步解锁。有效上限取站点、账号当前角色与本轮实际使用的题单三者中最低的一项。API 与学习 Worker 使用同一组服务配置变量：

- `KF_OJ_LEARNING_CHAT_MAX_HINT_LEVEL` 设置站点上限。
- `KF_OJ_LEARNING_MEMBER_MAX_HINT_LEVEL` 设置普通账号上限。
- `KF_OJ_LEARNING_ADMIN_MAX_HINT_LEVEL` 设置管理员账号上限。

这三个值均可设为 L0、L1、L2 或 L3，默认 L3。本人可在个人训练详情设置题单上限，后续周期继承该设置。训练对话按本人题单和不可变题目版本共同校验。服务端在读取授权证据、调用模型和交付回复时重新读取适用上限。题单标识不进入模型请求。

带题目上下文的 L0 至 L2 答疑由模型从本轮服务端候选中按提问选择一项。候选使用公开题面的指定章节、可用的公开样例和本轮获准的评测判定。L3 获准读取本人选定的源码片段后，由本地模型选择片段内的一条非空行和一种核对动作。没有授权片段时，L3 可引用本轮授权的评测判定或提出补充源码。服务端验证并自行交付对应内容。原始模型正文和思考不写入这些题目答疑的预览、终稿或检查点。普通对话可流式展示模型正文和思考。

旧式答疑工具的概念提示、评测历史和源码分别受站点与账号角色的 L1、L2 和 L3 上限约束。

L1 至 L3 的正文首次可供本人查看时，平台以账号和不可变题目版本记录一次时间。首次通过的提交发生在该时间之后时，复习按辅助通过安排，在上次通过满 7 天后优先复习。其他通过沿用 14 天间隔。L0 只澄清题意，思考预览也不计入这项记录。分类用于本人复习，对判题和比赛成绩没有影响。

已确认参赛的账号在比赛起止区间内无法调用学习助手。API 和学习 Worker 均按服务端时间检查，比赛结束后恢复访问。
